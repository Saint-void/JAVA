# Overview

As a software engineer, I am strengthening my foundation in Object-Oriented Programming (OOP), in-memory data structures, and robust user input handling in Java. Creating practical, interactive applications like this allows me to apply core engineering concepts such as encapsulation, state management, and exception handling in a clean, maintainable architecture.

This software is a lightweight, console-based Task Management System designed to help users track and organize their daily tasks. The application supports full CRUD (Create, Read, Update, Delete) operations and status tracking. Users can create tasks with detailed titles, descriptions, and priority levels (e.g., Low, Medium, High), view their current list of tasks with completion status markers (`[ ]` or `[X]`), edit existing tasks, mark tasks as complete, and delete tasks that are no longer needed.

The purpose of developing this software is to gain hands-on experience structuring Java applications using modular classes and collections. Specifically, it demonstrates:
* Encapsulating task data into a dedicated `Task` class using private instance variables, public getters/setters, and custom `toString()` formatting.
* Managing dynamic lists of objects using Java's `ArrayList`.
* Building a resilient CLI menu loop with input validation and `try-catch` exception handling to prevent runtime crashes from invalid user entries.
